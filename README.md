# ระบบสร้างรายงาน "สรุปการตรวจ รอยสัก-เจาะหู" อัตโนมัติ

ไม่ต้องมานั่งจัดวางรูปในเอกสารเองอีกต่อไป — โยนรูปใส่โฟลเดอร์ กรอกข้อมูลสั้น ๆ แล้วรัน 1 คำสั่ง ได้ไฟล์ Word พร้อมพิมพ์

## ติดตั้งครั้งแรก (ทำครั้งเดียว)

ต้องมี Python 3 ในเครื่อง แล้วติดตั้งไลบรารีที่ใช้:

```
pip install python-docx pillow
```

(ถ้าเครื่องมี Python หลายเวอร์ชัน อาจต้องใช้ `pip3` แทน `pip`)

## ใช้งานทุกรอบที่ต้องออกรายงาน

1. **เตรียมรูป** — สร้างโฟลเดอร์ย่อยในโฟลเดอร์ `photos/` หนึ่งโฟลเดอร์ต่อหนึ่ง "ชุด" ที่ยืนตรวจพร้อมกัน
   เช่น `photos/ชุดที่1`, `photos/ชุดที่2`, ... (ตั้งชื่อโฟลเดอร์อะไรก็ได้ ชื่อโฟลเดอร์จะกลายเป็นหัวข้อในรายงาน)

   ในแต่ละโฟลเดอร์ ใส่รูปแล้วตั้งชื่อไฟล์ให้มีคำว่า:
   - **หน้า** หรือ **front** → รูปมุมหน้า
   - **ข้าง** หรือ **side** → รูปมุมข้าง
   - **หลัง** หรือ **back** → รูปมุมหลัง

   ตัวอย่าง: `หน้า1.jpg`, `หน้า2.jpg`, `ข้าง1.jpg`, `หลัง.jpg`
   (ถ่ายมุมไหนไว้กี่รูปก็ใส่ได้ตามจริง สคริปต์จะเรียงเป็นแถวให้เอง — เหมือนต้นฉบับที่บางมุมมี 2 รูป บางมุมมี 1 รูป)

   ถ้าตั้งชื่อไฟล์ธรรมดา (ไม่มีคำใบ้) แต่มีพอดี 3 ไฟล์ต่อโฟลเดอร์ สคริปต์จะเดาให้ว่าไฟล์แรก=หน้า ไฟล์ที่สอง=ข้าง ไฟล์ที่สาม=หลัง ตามลำดับชื่อไฟล์

2. **แก้ `config.json`** ให้ตรงกับรอบที่ตรวจ:
   - `ครั้งที่`, `ภาคเรียน`, `ห้อง`
   - ผลสรุป (พบรอยสัก/ไม่มี, เจาะหู/ไม่มี) — ใส่ `true`/`false` ที่ `"checked"`
   - รายชื่อนักศึกษาที่พบรอยสัก (ถ้ามี) ในช่อง `students_with_tattoo`
   - ชื่ออาจารย์ผู้ตรวจ

3. **รันคำสั่ง**:
   ```
   python3 generate_report.py
   ```

4. ไฟล์ Word จะออกมาที่โฟลเดอร์ `output/` เปิดตรวจ พิมพ์ แล้วเซ็นชื่อได้เลย

## ปรับแต่งเพิ่มเติม

- **โลโก้วิทยาลัย**: เอาไฟล์รูปโลโก้มาวางในโฟลเดอร์นี้ ตั้งชื่อ `logo.png` (หรือแก้ path ใน `config.json` ช่อง `logo_path`) จะขึ้นหัวเอกสารให้อัตโนมัติ
- **ฟอนต์**: ค่าเริ่มต้นใช้ "TH Sarabun New" ถ้าเครื่องไม่มีฟอนต์นี้ ให้เปิด `generate_report.py` แล้วแก้ค่า `FONT_NAME` บรรทัดบนสุดของไฟล์ เป็นฟอนต์อื่น เช่น `Angsana New` หรือ `Sarabun`
- **จำนวนชุด/จำนวนคนต่อชุด**: ไม่จำกัด เพิ่ม/ลดโฟลเดอร์ใน `photos/` ได้ตามจำนวนจริงของแต่ละรอบ

## โครงสร้างไฟล์

```
report_generator/
├── generate_report.py     ← ตัวสคริปต์หลัก (ไม่ต้องแก้ ถ้าไม่ได้ปรับฟอนต์)
├── config.json             ← แก้ทุกรอบ
├── logo.png                ← (ถ้ามี) โลโก้วิทยาลัย
├── photos/
│   ├── ชุดที่1/
│   │   ├── หน้า1.jpg
│   │   ├── หน้า2.jpg
│   │   ├── ข้าง1.jpg
│   │   ├── ข้าง2.jpg
│   │   └── หลัง.jpg
│   └── ชุดที่2/
│       └── ...
└── output/                 ← ไฟล์รายงานที่สร้างเสร็จจะอยู่ที่นี่
```
